# IT23832794_singlish_sinhala_translator_playwright_tests

This repository contains the automation project for testing the **Chat Sinhala transliteration** function in the Pixelssuite Chat Translator web application.

Website under test:

```text
https://www.pixelssuite.com/chat-translator
```

# Project Purpose

The purpose of this project is to automate negative test cases for the Chat Sinhala transliteration feature.The automation checks whether chat style Singlish inputs are converted correctly into Sinhala output.

The actual output generated by the website is compared with the expected Sinhala output recorded in the Excel test case file.

# Assignment Scope

This project tests only the following feature:

```text
Chat Sinhala transliteration function
```

The following areas are outside the scope of this project:

- Standard Sinhala transliteration
- Backend API testing
- Performance testing
- Scalability testing
- Security testing

# Test Case Type

This project contains **50 negative test cases**.

A negative test case means the actual output generated by the website is different from the expected correct Sinhala output.

```text
Actual output ≠ Expected output
```

Therefore, the status of each negative test case is recorded as:

```text
Fail
```

## File Descriptions

# test_automation.py

This is the main automation script.

It performs the following actions:

1. Opens the Pixelssuite Chat Translator website.
2. Selects or uses the Chat Sinhala transliteration function.
3. Reads Singlish inputs from the Excel test case file.
4. Enters each Singlish input into the website.
5. Captures the Sinhala output generated by the website.
6. Saves the captured result as the actual output.
7. Compares the actual output with the expected output.
8. Updates the test result status.

## How to Run the Automation Tests

Run the following command from the project root folder:

```bash
python test_automation.py
```

The automation script will open the website, run the test cases, capture actual outputs, and update or support the Excel test results.

## Expected Automation Flow

The automation follows these steps:

1. Open the website:

```text
https://www.pixelssuite.com/chat-translator
```

2. Use the Chat Sinhala transliteration function.

3. Read test case data from:

```text
IT23832794_Assignment 1 - Test cases.xlsx
```

4. Enter the Singlish input into the website input field.

5. Wait until the Sinhala output is generated.

6. Capture the website generated Sinhala output.

7. Save the captured output into the "Actual output" column.

8. Compare the actual output with the expected output.

9. Mark the status as "Fail" when the outputs are different.

## Actual Output Handling

The "Actual output" should not be manually guessed.

It must be captured from the live website during the Playwright automation run.

Example:

```text
Input:
oya gedara innawada?

Expected output:
ඔයා ගෙදර ඉන්නවද?

Actual output:
Website generated Sinhala output

Status:
Fail
```

## Negative Test Case Validation

A test case is valid as a negative test case only when:

```text
Actual output is different from Expected output
```

If the actual output is exactly the same as the expected output, that test case should be reviewed or replaced because it is not a valid negative test case.
